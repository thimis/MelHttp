Malbolge corner

This site is served by MelHttp, a Go web server with a twist: every file is compiled ahead of time into a Malbolge program, and each response is produced by running that program in a Malbolge interpreter. In other words, every byte of this page was printed by a Malbolge program, one out instruction at a time. The headers below show how much work that took.
